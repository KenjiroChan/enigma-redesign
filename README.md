# Enigma Escape Room — website redesign (concept)

A UX case study prototype by **Kenjiro Chan**: a redesign of the website for Enigma Escape Room in downtown Toronto, built around an availability-first booking flow (pick a date and group size, then see every room that's open) and a visual system based on the Enigma cipher machine.

**This is a portfolio concept, not the official Enigma Escape Room website.** Nothing on it can be booked. To play, visit [enigmaroom.ca](https://www.enigmaroom.ca).

## Pages

- `index.html` — homepage with the room finder, "open next tonight" panel and filterable room list
- `room.html` — a room page (Exorcist)
- `book.html` — clickable booking prototype (sample availability, nothing is sent or stored)
- `groups.html` — groups and events inquiry page

Room photography, review text and some venue policies are placeholders. Times shown are illustrative.

Plain HTML, CSS and JavaScript with no build step.
